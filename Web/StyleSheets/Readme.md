### Appearance Modern 

The css document includes styling to modernize the appearance of Infor CRM. Plain
and simple. You will need to include it in the css folder of the portal for deployment as 
well as alter your Core.Master file to link the css file after the Sage-Styles.css entry.

It provides cleaner typography, and a more materal based design on the controls, grids, tabs,
etc.

User at your own risk (though there should not be much), however testing in your environment before
production deployment is advised.
